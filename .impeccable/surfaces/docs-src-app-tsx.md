# Surface Brief: SusuEdition Presentation Site (`docs/src/App.tsx`)

- **Scope:** Whole surface (`/docs` GitHub Pages presentation site)
- **Visitor Mode:** Persuade
- **Audience & Job:** Creators, photographers, and everyday video makers on Windows 11 and Android looking for a fast, local-first tool to sync videos to music beats or assemble photo collages without cloud uploads or timeline complexity.
- **Primary Action:** Download the latest release for Windows 11 (`.exe` / `.msi`) or Android 8.0+ (`.apk`) from GitHub Releases.
- **Proof & Content:** Real product screenshots (`video-maker.png`, `video-maker-music.png`, `video-maker-filters.png`, `photo-collage.png`, `photo-collage-filters.png`, `home.png`, `og.png`), interactive beat-sync timeline playground (Dynamic, Steady, Bars, Accents + BPM waveform + flexibility slider), interactive photo collage layout/aspect explorer, and local-first architecture breakdown (Tauri v2, Rust `susu://` HTTP Range protocol, Symphonia beat engine, WebCodecs + WebGL2).

## Direction contract

- **THESIS:** The page is a live beat-synced studio deck where musical rhythm and local hardware precision can be felt and tested in the first viewport—refusing generic SaaS marketing templates, fake floating 3D blobs, or static icon-card grids.
- **OWN-WORLD:** Deep obsidian dark studio canvas (`oklch(0.13 0.005 285)`) with crisp light-mode counterpart (`oklch(1 0 0)`), rose-coral primary signal (`oklch(0.7 0.17 15)` / `#f43f5e`) paired with violet spectrum (`#a855f7`) and cyan Tauri accents (`#24c8db`), Geist Variable display and UI typography, tabular timecode readouts (`0:20.0 · 120 BPM · 9/9 on beat`), razor-sharp `1px` hairline studio borders, and tactile Animate UI icons/controls on every interactive surface.
- **STORY:** Visitors immediately see and interact with how SusuEdition locks video cuts onto musical beats and frames multi-photo collages locally on their GPU, inspect real unretouched desktop screens across Video Maker and Photo Collage modes, verify the zero-upload Rust + WebCodecs architecture, and download the installer for Windows 11 or Android.
- **FIRST VIEWPORT:** A full-width studio stage: top frameless-inspired navigation bar with SusuEdition logo, interactive section links, theme toggle, GitHub repo link, and direct Download CTA; main asymmetric studio console combining the bold headline ("Your moments, on the beat.") and direct Windows 11 / Android download triggers on the left with a live interactive Beat-Sync Timeline Deck + real Video Maker studio frame on the right where visitors can switch between Dynamic, Steady, Bars, and Accents modes and watch cuts snap to the 120 BPM waveform in real time.
